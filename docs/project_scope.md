# Project Scope

## User
AI 产品经理求职者，主要面向 DeepSeek（深度求索）、Kimi（月之暗面）、GMT（阶跃星辰） 等头部AI大模型公司。

## Input
1. 目标岗位 JD（来自公开渠道，存于 data/raw/jd_raw.csv，包含公司、岗位、JD原文等字段，共计30条）
2. 求职者简历（脱敏后的 Markdown 文本，存于 data/resume/resume.md）

## Output
1. 能力差距诊断
2. 以周为单位的对齐计划
3. 简历 Bullet 改写建议

## Non-goals（不做的事及原因）
- 不做多 Agent 协作（两周内控制项目复杂度，聚焦单 Agent + 工具调用 + 自检闭环。）
- 不微调模型（微调成本高且无法实时更新知识，优先用 RAG 解决知识时效性问题。）
- 不做移动端（当前核心是验证逻辑，不在前端适配和多端适配上消耗时间。）
- 不做登录和权限系统（脱敏数据，本地运行/Demo 演示，不需要账号体系。）
- 不做大规模爬虫（使用公开手动采集的 30 条 JD 即可验证闭环，避免反爬和法律风险。）
## Success Metrics
- 引用准确率 > 80%
- 任务完成率 > 85%
- 单次成本 < 0.05 元
- P95 延迟 < 15 秒
